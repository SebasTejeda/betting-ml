# betting-ml

Modelo de machine learning para predecir partidos de fútbol (1X2) de las 5 grandes ligas europeas, detectar *value bets* y consultar los partidos del día mediante una API REST.

> Este README es provisional. El agente lo reescribe al final (tarea T038) con resultados, arquitectura e instrucciones completas.
